Imitation learning from grui recordings

Convert screen/kb-mouse recordings (made by the grui add-on, installed from the Modules page) into a fine-tuning set, or run grui's own dataset builder and behavior-cloning training.

1) Recordings → mama fine-tuning set

Each F9 annotation becomes one example: instruction = the annotation label (or your task text below), response = the plain-language action transcript.

Saved under the grui add-on's recordings/ folder
If blank, the annotation label is used ("Demonstrate: <label>"); with markers absent the whole recording becomes one example.

2) grui raw dataset builder

Runs grui dataset build <recording> --out <dir> — temporally aligned observation→action samples in grui's own format (input for the step below).

3) grui imitation training

Runs grui train --dataset <dir> --out <ckpt> — CNN+GRU behavior-cloning policy from built datasets (needs the grui [ml] torch extra).

CSV / TSV to fine-tuning set

Pick a CSV, TSV or similar delimited file, choose which columns are the instruction and the response, preview a few rows, and build a JSONL fine-tuning set.
