Results

—
Achieved FLOPS
The real throughput measured across many forward passes. This is what your hardware actually delivers for this workload.
—
Peak FLOPS (spec)
The manufacturer's theoretical maximum. Real workloads almost never reach this due to memory bandwidth, kernel launch overhead, and operation mix.
—
Utilization
—
FLOPs / Forward Pass
Analytical count of floating-point operations required for a single forward pass of the model. Fixed for a given model/input size — hardware independent.
—
Throughput
Inferences per second — how many forward passes the hardware completes in one second of wall-clock time.
—
Model Parameters
Total number of trainable weights. Larger models have more parameters and require more FLOPs per pass.
—
Benchmark Duration
Total wall-clock time for all measured forward passes (excluding warmup). Longer runs yield more stable measurements.
—
Batch Size / Input
Batch size used for the benchmark and the input spatial resolution. Larger inputs increase FLOPs per pass.
